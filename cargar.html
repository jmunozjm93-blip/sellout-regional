Repositorio:
¿Cómo creo el token?
  1. Entra a github.com/settings/personal-access-tokens/new (o edita el que ya usas en Cargas o Levantamiento)
  2. Token name: sellout regional · Expiration: 1 año
  3. Repository access: "Only select repositories" → agrega sellout-regional
  4. Permissions → Repository permissions → Contents: Read and write (nada más)
  5. Generate token → cópialo y pégalo arriba. Queda guardado solo en este navegador.
